Problemes d'indexation identifies

Critique Detectee, actuellement non indexee
79 pages

Google a decouvert ces pages mais a choisi de ne pas les indexer. C'est le probleme principal qui bloque 84% de votre site. Source : Systemes Google — Validation : Non commencee.

  • Rendu client-side (CSR) : Les pages d'experience ne montrent que des skeleton loaders dans le HTML initial. Googlebot ne voit aucun contenu reel (pas de titre, description, prix, avis).
  • Titres et meta descriptions dupliques : Les ~20 pages d'experience partagent toutes le meme titre generique "Experience de voyage — Okeyo Travel" et la meme meta description.
  • Contenu mince (thin content) : Les pages Explore (~350 mots), Collections (~150 mots) et Categories (~350 mots) manquent de profondeur pour que Google juge utile de les indexer.
  • Faibles signaux E-E-A-T : Absence de page "A propos", pas de blog, pas de guides — Google ne voit pas d'expertise demontree.
Haute Page avec redirection
3 pages

3 URLs presentes dans le sitemap redirigent vers d'autres pages. Google n'indexe pas les URLs qui effectuent une redirection. Source : Site Web — Validation : Non commencee.

  • URLs obsoletes dans le sitemap : Des URLs qui ont ete deplacees ou renommees sont encore referenceees dans sitemap.xml. Elles doivent etre remplacees par les URLs de destination finale.
Moyenne Page en double sans URL canonique
1 page

Google detecte un doublon et n'a pas de balise canonical claire pour determiner quelle version indexer. Source : Site Web — Validation : Non commencee.

  • Canonical manquante ou ambigue : La page dupliquee ne specifie pas explicitement via <link rel="canonical"> quelle est la version principale a indexer.
