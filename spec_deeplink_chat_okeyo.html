Structure des URLs
Chaque pub Facebook aura sa propre URL. Le paramètre property est le slug unique de la propriété dans ta base de données.
https://okeyotravel.com/ar/chat?property=dar-zitoun&utm_source=fb&utm_medium=paid&utm_campaign=riad-marrakech-mai26
/ar/chat — Page chat en arabe (/fr/chat pour FR)
property — Paramètre clé : slug de la propriété
valeur — Slug unique de chaque riad/lodge dans ta DB
utm_* — Pour tracker dans PostHog par propriété
Paramètres — Table de référence
Tous les paramètres URL supportés par le système. Seul property est obligatoire pour déclencher le mode deep link.
Paramètre Type Exemple Description Statut
property string dar-zitoun Slug unique de la propriété dans la DB. Doit correspondre exactement à l'ID/slug utilisé dans Supabase. Requis
lang string ar / fr / en Langue du chat. Si absent, déduit depuis l'URL (/ar/chat → ar, /fr/chat → fr). Utilisé pour choisir le bon prompt. Optionnel
promo string OKEYO5 Code promo à mentionner dans le premier message de l'IA. Si présent, l'IA annonce le discount dès le début. Optionnel
checkin date 2026-06-15 Date d'arrivée pré-remplie. L'IA utilise cette date dans sa présentation des disponibilités. Optionnel
nights number 2 Nombre de nuits. Permet à l'IA de calculer et présenter le prix total directement. Optionnel
utm_source string fb Source tracking PostHog. Permet de savoir quelle pub a généré la conversation et la réservation. Tracking
utm_campaign string riad-marrakech-mai26 Nom de la campagne Facebook. Permet de comparer les performances par campagne dans PostHog. Tracking
Code — Frontend (JavaScript)
Ce code va dans le composant de la page /chat. Il lit l'URL, récupère les données du riad depuis Supabase, et injecte le contexte dans l'agent IA avant de démarrer la conversation.
JavaScript / TypeScript app/[lang]/chat/page.tsx (ou ChatPage.jsx) 
// ─────────────────────────────────────────────────────
// ÉTAPE 1 — Lire les paramètres URL à l'arrivée sur /chat
// ─────────────────────────────────────────────────────

const getDeepLinkParams = () => {
  const params = new URLSearchParams(window.location.search)
  return {
    property:  params.get('property'),   // ex: "dar-zitoun"
    lang:      params.get('lang'),       // ex: "ar" ou "fr"
    promo:     params.get('promo'),      // ex: "OKEYO5"
    checkin:   params.get('checkin'),    // ex: "2026-06-15"
    nights:    params.get('nights'),     // ex: "2"
    utmSource: params.get('utm_source'), // ex: "fb"
    utmCampaign: params.get('utm_campaign')
  }
}

// ─────────────────────────────────────────────────────
// ÉTAPE 2 — Récupérer les données du riad depuis Supabase
// ─────────────────────────────────────────────────────

const fetchPropertyData = async (slug: string) => {
  const { data, error } = await supabase
    .from('properties')
    .select('*')
    .eq('slug', slug)
    .single()
  
  if (error || !data) return null
  return data // { name, name_ar, description_ar, price_per_night, rating, location, amenities, images... }
}

// ─────────────────────────────────────────────────────
// ÉTAPE 3 — Construire le contexte à injecter dans l'IA
// ─────────────────────────────────────────────────────

const buildDeepLinkContext = (
  property: PropertyData,
  params: DeepLinkParams
) => {
  return {
    // Ce qui sera envoyé au système prompt de l'IA
    systemContext: {
      mode: 'deep_link_property',
      property: {
        id:           property.id,
        name:         property.name_ar,      // nom en arabe
        description:  property.description_ar, // desc en arabe
        price:        property.price_per_night,
        rating:       property.rating,
        location:     property.location,
        amenities:    property.amenities,    // ["piscine", "hammam", ...]
        images:       property.images.slice(0, 3)
      },
      userContext: {
        source:       params.utmSource,   // "fb" → vient d'une pub Facebook
        promo:        params.promo,       // "OKEYO5" si présent
        checkin:      params.checkin,     // date si dans l'URL
        nights:       params.nights       // nuits si dans l'URL
      }
    }
  }
}

// ─────────────────────────────────────────────────────
// ÉTAPE 4 — Démarrer la conversation automatiquement
// À appeler dans useEffect() au montage du composant
// ─────────────────────────────────────────────────────

useEffect(() => {
  const initDeepLink = async () => {
    const params = getDeepLinkParams()
    
    // Pas de paramètre property → affichage normal du chat
    if (!params.property) return
    
    // Tracker dans PostHog pour mesurer les conversions par pub
    posthog.capture('deep_link_chat_opened', {
      property_slug: params.property,
      utm_source:    params.utmSource,
      utm_campaign:  params.utmCampaign
    })

    // Récupérer les données du riad
    const property = await fetchPropertyData(params.property)
    if (!property) return // propriété non trouvée → chat normal

    // Construire le contexte et démarrer le chat automatiquement
    const context = buildDeepLinkContext(property, params)
    
    // Envoyer le premier message IA automatiquement (sans input user)
    startChatWithContext(context) // ta fonction existante d'envoi de message
  }

  initDeepLink()
}, []) // exécuté une seule fois au montage
Prompt — Agent IA (version arabe)
Ce prompt système est injecté automatiquement quand un paramètre property est détecté. Il remplace ou complète ton system prompt habituel. L'IA sait qu'elle doit présenter ce riad spécifique et proposer la réservation.

Tracking — Événements PostHog à ajouter
Ces événements permettront de mesurer précisément le ROI de chaque pub Facebook. Tu pourras voir dans PostHog combien de clics de pub ont abouti à une réservation, par propriété et par campagne.
PostHog Events À ajouter dans le code du chat 
// 1. Quand le chat deep link s'ouvre
posthog.capture('deep_link_chat_opened', {
  property_slug: 'dar-zitoun',
  utm_source:    'fb',
  utm_campaign:  'riad-marrakech-mai26'
})

// 2. Quand l'user répond au premier message de l'IA
posthog.capture('deep_link_first_reply', {
  property_slug: 'dar-zitoun',
  reply_type:    'booking_intent' // ou 'more_info' ou 'other'
})

// 3. Quand la réservation est confirmée
posthog.capture('deep_link_booking_completed', {
  property_slug: 'dar-zitoun',
  revenue_mad:   1615,
  utm_campaign:  'riad-marrakech-mai26',
  promo_used:    'OKEYO5'
})

Points d'attention
⚠️
Le slug doit être en minuscules avec tirets, sans accents. Assure-toi que les slugs dans ta DB correspondent exactement à ceux dans les URLs Facebook. Une typo = chat normal affiché sans contexte (mais pas d'erreur visible pour l'user).
💡
Mise en cache recommandée. Les données des propriétés changent rarement — mets en cache le résultat de fetchPropertyData() pendant 1h (Redis ou localStorage) pour éviter un appel Supabase à chaque clic de pub Facebook.
✅
Ce système est rétrocompatible. Si l'URL ne contient pas de paramètre property (visite directe, partage de lien, etc.), le chat s'affiche normalement avec les suggestions habituelles. Aucune régression possible.
